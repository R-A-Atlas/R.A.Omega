Fresh start — like a brand-new account

This is the same as wiping the app and opening it for the first time. After you run it:

  • Every report HTML and helper file under deep_reports/ and reports/ is deleted.
  • Your watchlist tickers and saved stocks/options are cleared (the JSON files are emptied).
  • Long-term memory (atlas_memory.db) is removed — nothing remembered per ticker.
  • SEC / RAG vector store under atlas_rag/ is wiped (embeddings rebuilt on future research).
  • Track record, alerts, congress cache, deltas, and related logs are cleared.

Home will show no positions, no watchlist, no embedded report — your next Search is the first deep research again. .env API keys stay. If a database file will not delete, stop the dashboard (Ctrl+C) and run reset once more.
