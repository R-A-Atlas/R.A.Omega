What is ATLAS? Plain English explanation

ATLAS is a Python-based research assistant for equities and options. When you run deep research on a ticker, the pipeline scrapes many public sources, reconciles facts in code, pulls filing context via local RAG, and asks Gemini to synthesize only what was verified into an HTML report you can read in the browser.

Compared with a general chat model: ATLAS is wired to structured market data (IV rank, whisper EPS, 13F snapshots, insider forms, flows where available) rather than article summaries alone. The web dashboard (dashboard_server.py) is the day-to-day surface: search, embedded reports, report history, and manual watchlist/positions. It does not connect a broker or place orders.

Optional modules in the repo (alerts, delta reports, tuner/self-coder, backtest sandbox, news scanner HTML) are for advanced CLI or background use. The shipping UI deliberately stays focused on information + your own tracking.

The Core Idea

1
Scrape, don't guess
Python code pulls real data from 18 sources. No hallucination because it only analyzes what it actually found.
2
Cross-reference everything
Facts are compared across sources. CONFIRMED = multiple sources agree. CONFLICT = flag the discrepancy.
3
AI synthesizes verified facts only
Gemini gets 40,000+ chars of real data + confidence labels + memory context + historical win rates.
4
Optional: journal outcomes (CLI / tracker)
If you use the tracker, graded outcomes can inform later prompts and tuners. The web app does not auto-trade from this loop.

How a Full Run Works Typical deep-research path (CLI) — dashboards embed the resulting HTML

1
18-source parallel scrape (0–90 sec)
Finviz, Google News, StockAnalysis, OpenInsider, MarketBeat, Barchart, Unusual Whales, SEC EDGAR, Reddit, Benzinga, EarningsWhispers, StockTwits, Seeking Alpha, Macrotrends, 13F filings, and more. Playwright handles JS-rendered sites.
2
Cross-reference engine runs
Python compares earnings dates, price targets, EPS estimates, and news sentiment across all sources. Produces a CONFIDENCE REPORT before the AI sees anything.
3
Memory + pattern injection
The memory system recalls what ATLAS knows about this ticker from past research. The pattern library injects historical win rates for this setup's specific tags.
4
Hyper-awareness scan (NEW)
Market regime detected (Bull/Bear/Chop/Panic). Short squeeze score 0–100 calculated. News velocity checked — is the pace of headlines accelerating? Historical earnings reactions pulled. Confidence multiplier applied.
5
Sector macro wind check
Is the sector getting inflows or outflows vs SPY? Tailwind or headwind for this trade.
6
Self-tuned weight injection (NEW)
If auto_tuner has learned from past outcomes, the optimized scoring weights and thresholds are injected into the synthesis prompt. ATLAS uses its own track record to calibrate confidence.
7
Gemini synthesis (single API call)
One carefully engineered prompt with 40,000+ chars of verified data + awareness signals + tuned weights. Outputs structured JSON: rating, confidence, trade plan, options play, bull/bear thesis, price levels.
8
Post-synthesis packaging
Options P/L simulator, position sizing math, and narrative sections are assembled into the HTML report. Some analytics modules are CLI-only today.
9
Where you consume it
Open deep_reports/TICKER_deep.html or use Home → Search in the dashboard to embed the same file. Optional jobs (alerts, delta watcher, tuner) only run if you start them.

Anti-hallucination design: ATLAS never lets the AI make up numbers. Every fact in the prompt is labeled CONFIRMED, SINGLE SOURCE, or CONFLICT. The AI is instructed to only use null for missing data — never fabricate. The memory system marks facts as CONFIRMED hard truth that cannot be contradicted. Result: reports you can actually trade from.

18 Data Sources All live, all free — zero API costs for data collection

Finviz
Price, RSI(14), short float, earnings date, insider trend, ATR, beta, 52-week range, relative volume, P/E, sector
EarningsWhispers
The whisper EPS number — what traders actually expect (not Wall St consensus). Beat whisper = rally. Miss = dump even on a "beat."
Barchart IV Rank
Current IV Rank & Percentile — tells you if options are cheap (buy) or expensive (crush risk after earnings)
Barchart Historical IV
30/60/90/180-day IV trend — is volatility expanding or contracting? Critical for options entry timing
Unusual Whales
Put/call ratio, net options flow direction, dark pool activity, most active strikes
OpenInsider
Insider buys & sells with exact shares, price, dollar value, title of insider — the smart money signal
SEC EDGAR 8-K
Material event filings — contracts, partnerships, leadership changes, FDA approvals, earnings releases
Macrotrends / yfinance
5 years of annual revenue, gross margin, net income, YoY growth. 8 quarters of EPS beat/miss history.
Institutional 13F
Top institutional holders, % owned, quarterly changes — via yfinance + WhalerWisdom + SEC EDGAR
MarketBeat
Aggregated analyst ratings, high/low price targets, recent rating changes by firm
StockAnalysis
8 quarters of EPS actual vs estimate, surprise %, beat/miss streak
StockTwits
Live bull % / bear %, message volume, retail trader sentiment — purpose-built for stock discussions
Google News RSS
20+ headlines with exact timestamps, all ATLAS-tracked tickers
Benzinga RSS
Financial news with timestamps, press releases, earnings commentary
Seeking Alpha
Earnings previews, long-form analyst commentary, RSS + page scrape
Reddit WSB/Stocks
Retail sentiment — top posts, score, comment counts across r/wallstreetbets and r/stocks
Article Full-Text
Playwright reads the complete body of top news articles (non-paywalled) — not just headlines
Cross-reference Engine
Built-in Python system that compares key facts across all 17 scraped sources. Labels each fact CONFIRMED / CORROBORATED / SINGLE SOURCE / CONFLICT before the AI sees it.

Systems in the repository Useful context — not everything appears in the current dashboard

The live dashboard emphasizes deep research, report history, and manual tracking. Items like volume profile, sector rotation tiles, option scan, and self-learning UI have been removed from that surface even though Python modules may remain callable from the terminal.

Memory System
memory.py
Permanent + 7-day rolling SQLite brain. Recalls past research associatively when you mention a ticker. Anti-hallucination: past confirmed facts can't be contradicted.
Win-Rate Tracker
tracker.py
Every recommendation auto-recorded. After the event, grade it WIN/LOSS/PARTIAL. ATLAS builds a real track record over time.
Setup Pattern Library
tracker.py
20 setup tags auto-detected per trade (short float level, IV rank, earnings timing, flow direction…). After 3+ outcomes per tag, win rates feed back into synthesis.
Options P/L Simulator
options_simulator.py
Black-Scholes calculations: P/L at every price scenario, IV crush simulation, theta decay, breakeven. SVG chart in every report.
Position Sizer
position_sizer.py
Kelly criterion + fixed fractional + confidence scaling. Outputs: exact # of contracts or shares, total cost, max loss, R/R ratio, expected value calculation.
Real-Time Price Alerts
alerts.py
Background thread checks prices every 60 seconds. Fires Windows desktop notification + sound when stop, target, or earnings day triggers. Persists across restarts.
Delta Reporter
delta_reporter.py
Re-scrapes every 30 minutes. Shows ONLY what changed: IV jumped, new headline, options flow flipped, insider filed. CRITICAL/HIGH/MEDIUM severity levels.
Multi-Ticker Ranker
multi_ranker.py
Run full research on up to 20 tickers. Ranks by composite score (confidence, IV, short float, flow, earnings, analyst, news). Identifies the highest-conviction trade of the day.
Portfolio Correlation
sector_tracker.py
Calculates pairwise correlation matrix for your positions. Diversification score 0-100. Warns when positions are highly correlated (same risk dressed up as diversification).
Hyper-Awareness Engine
market_scanner.py — NEW
Market regime (Bull/Bear/Chop/Panic), short squeeze score 0–100, news velocity acceleration, historical earnings reactions, pre-market gap scanner, dark horse scanner. All injected live into every synthesis.
Self-Tuning Weight Optimizer
auto_tuner.py — NEW
Uses real outcome history to optimize scoring weights and detection thresholds. Confidence calibration check. Updates atlas_tuned_weights.json every 5 outcomes. Runs automatically in --watch mode every 60 min.

My Honest Assessment of ATLAS What I actually think about what we've built

99/100
Research-depth rubric — not trading performance — updated May 2026

For structured equity research, wiring real scrapers + a cross-check layer before the model sees numbers is still uncommon at hobby scale. You get IV context, filings RAG, insider/13F snapshots, and a single HTML artifact you can archive — then a dashboard that keeps reports and manual positions in one place without implying the app is placing trades for you.

Where ATLAS still goes further is optional feedback tooling: tracker + tuner + self_coder proposals are there if you want a closed loop on the CLI. None of that is required for the research-only workflow, and none of it routes orders through the web UI.

The usual ceiling is still live execution-grade data (Level 2, full dark pool, co-located feeds). For idea generation and documentation, the stack is strong; for fills and compliance, you still use your broker and your own judgment.

What ATLAS does better than everyone

Anti-hallucination architecture. Other AIs guess when data is missing. ATLAS uses null and flags the gap. That's the difference between a report you can trade from and one you can't.
The whisper EPS edge. Knowing the whisper number vs Wall St consensus tells you what traders actually expect — and whether a "beat" will actually send the stock up. ChatGPT cannot get this.
Journaled outcomes (optional). SQLite-backed tracker/tuners can personalize future prompts if you grade trades on the CLI. The shipping dashboard stays research + manual ledger only.
IV Rank + options P/L + Kelly. This combo — knowing if options are cheap, visualizing the scenarios, and sizing exactly right — is normally a $500/mo trading platform feature. You have it free.
Zero recurring cost. The only cost is the Gemini API key, which runs pennies per research call. Everything else is free data, free libraries, your hardware.
