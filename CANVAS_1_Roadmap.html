ATLAS — Product snapshot

Aligned with the research + manual tracking web app (May 2026). Older roadmap items that assumed Alpaca paper trading, an “autonomous execution” layer, or dashboard widgets for sector rotation / option scan / volume profile are removed from the product surface — some code may remain for optional CLI use.

Shipped in the web UI (dashboard_server.py + dashboard.html, port 8765): Home search → deep research → embedded deep_reports/TICKER_deep.html; report history; watchlist; manual stocks/options with per-leg remove; manual portfolio totals; workspace reset (reports, caches, SQLite, RAG files); settings copy that states ATLAS is informational and does not trade for you.
Backend / CLI still available (not promoted in the dashboard): multi-source scrape + rag_engine.py (Chroma), deep_research.py, optional --watch / news_scanner → LIVE_REPORTS.html, tracker/memory/auto_tuner/self_coder modules, --backtest, etc. Treat these as power-user or experimental unless you wire them back into the UI.
