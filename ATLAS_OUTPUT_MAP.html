ATLAS — Where every output goes

Quick map for deep research, the web dashboard, and optional background jobs. This page is documentation only — it is not refreshed by the app.

Product focus (web app): The live UI is dashboard.html served by dashboard_server.py at http://localhost:8765. It is built for deep research reports, report history, and manual watchlist / position tracking. It does not connect a broker, place orders, or run autonomous “agent” trading. Optional Python modules (volume profile, sector rotation, paper trading helpers, etc.) may still exist on disk for CLI use — they are not surfaced in the current dashboard.
Deep research (python auto_bot.py --deep-research TICKER)
Python → multi-source scrape + RAG (SEC filings in atlas_rag/) + synthesis → writes deep_reports/TICKER_deep.html (ticker uppercase). Append/update behavior keeps one rolling file per ticker. Discovery runs → deep_reports/DISCOVERY_*.html.

Web dashboard (python auto_bot.py --dashboard or run dashboard_server.py)
Browser UI loads state from the server; home search triggers deep research and embeds the latest HTML report. Portfolio totals come from positions_cache.json (manual entries only). Watchlist: watchlist.json. Report history: research_history.json + files under deep_reports/.

Watch / news mode (python auto_bot.py --watch or --news-only)
Optional. The news scanner can refresh LIVE_REPORTS.html and per-ticker sheets under reports/ from whatever tickers are in the manual position cache (and related config). This path is separate from the dashboard embed; open LIVE_REPORTS.html only when you are actively running that job.

Legacy intraday HTML (LIVE_DASHBOARD.html)
If you still run the older intraday/template pipeline that injects into stock_research_v3.html, that job may update LIVE_DASHBOARD.html and agent_output.json. The primary UI is still the :8765 dashboard — treat LIVE_DASHBOARD.html as optional / legacy unless you rely on that scheduler.

Data reset
Settings → “Fresh start” calls /reset_workspace, which clears manual caches, report folders, congress cache, tracker/memory SQLite, and Chroma files under atlas_rag/ (local only).
Quick open: after research, your latest deep report is deep_reports/TICKER_deep.html. The same report appears embedded on Home when you search from the dashboard.
