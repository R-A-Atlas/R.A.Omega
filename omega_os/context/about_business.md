# About the Business

## Name
R.A. Omega (Research & Analysis Omega)

## Category
Finance Intelligence Operating System — AI-powered institutional-grade analysis for retail traders

## Core Value Proposition
Any finance question → 10+ free data sources fetched in parallel → one Gemini synthesis →
institutional-grade analysis in under 3 minutes for ~$0.017/query.

## Two AI Brains
- **POST /query** → QueryRouter + FourLoopEngine (10 loops, deep equity/options)
- **POST /omega** → OmegaAgent (fast, cross-domain: debt, cars, mortgages, macro)
