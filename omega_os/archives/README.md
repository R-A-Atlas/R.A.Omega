# Archives

Old versions of context files and retired skills.
Keep for reference — do not delete.

## When to Archive
- Context file updated with breaking changes: move old version here as context_<name>_<date>.md
- Skill retired or replaced: move old skill.md here as skills_<name>_<date>.md
- Major architecture decision reversed: log in decisions/ and archive old approach here

## Format
`<type>_<name>_<YYYY-MM-DD>.md`

Examples:
- context_about_user_2026-05-15.md
- skills_company_report_2026-06-01.md
