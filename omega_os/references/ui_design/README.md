# UI Design Reference

## Color Palette
- Background (dark): #0a0a0a
- Surface: #111111
- Surface elevated: #1a1a1a
- Accent (teal): #00D4AA
- Text primary: #FFFFFF
- Text secondary: #888888
- Success: #22C55E
- Warning: #F59E0B
- Error/Bear: #EF4444
- Bull: #22C55E

## Typography
- Font family: Inter (Google Fonts)
- Heading: Inter 700
- Body: Inter 400
- Mono (code/numbers): JetBrains Mono or system-mono

## Component Standards
- Cards: rounded-lg (8px), border 1px solid #222, background #111
- Memo/Intelligence Brief: teal left border (3px solid #00D4AA), background #0d1f1a
- RYG meters: Red (#EF4444) / Yellow (#F59E0B) / Green (#22C55E)
- Buttons: teal fill, white text, rounded-md

## Layout
- Sidebar: 280px fixed, sessions list
- Main content: flex-1, max-width 900px centered
- Header: fixed top, regime chip, model badge

## Key UI Phrases (Brand Voice)
- "BOTTOM LINE" not "Summary"
- "THE SETUP" not "Background"
- "HOW THIS PLAYS OUT" not "Scenarios"
- "WHAT BREAKS THIS" not "Risks"
- "YOUR RULES" not "Execution Rules"
- "INTELLIGENCE BRIEF" not "Analyst Note"
- Input placeholder: "What do you want to know about your money?"
- Footer in standalone reports: "117 agents active"
