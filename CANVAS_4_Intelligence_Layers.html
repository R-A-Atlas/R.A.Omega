market_scanner.py
Hyper-Awareness Engine
LIVE
Market Regime Detector
Bull / Bear / Chop / Panic — adjusts confidence multiplier automatically (0.5x in panic, 1.15x in bull). Based on SPY, QQQ trend + VIX level.
Short Squeeze Score (0–100)
Composite: short float (35 pts), days-to-cover (20 pts), relative volume (15 pts), vs 20-day MA (10 pts), IV rank (10 pts), 5-day momentum (10 pts). Score 80+ = squeeze imminent.
News Velocity Tracker
Detects if headlines are accelerating. 5 articles/hour vs 0.4/hour baseline = breaking news signal — often fires before the stock moves.
Earnings Reaction Database
Actual % moves on last 8 earnings days: average move, beat rate, avg beat/miss reaction, best move, worst move. Tells you if this stock is a high mover on earnings.
Pre-Market Gap Scanner
Scans watch list before open. Gaps >2% with volume ratio flagged as HIGH or MEDIUM urgency with trading signal.
Dark Horse Scanner
Finds tickers matching your best win patterns — squeeze candidates you aren't watching yet. Scored by short float, days-to-cover, relative volume.
auto_tuner.py
Self-Tuning Weight Optimizer
LIVE
Ranker Weight Optimizer
Coordinate ascent on 7 scoring dimensions. Shifts weight toward signals that actually predicted wins. Saves to atlas_tuned_weights.json.
Threshold Tuner
Finds optimal short float %, IV rank cutoffs from your outcome history. E.g., if SF > 30% won 79% but SF > 20% only won 52%, updates the threshold to 30.
Confidence Calibration Check
Checks if conf=8/10 actually wins 80% of the time. If ATLAS is overconfident, flags it and applies a deflation multiplier. If underconfident, can size slightly bigger.
Auto-Trigger
Runs every 5 graded outcomes. Also runs every 60 minutes in --watch mode. Zero manual steps needed.
self_coder.py
Self-Improvement Engine
LIVE
Loss Pattern Analyzer
Reviews all LOSS outcomes and finds systematic failures: IV crush on earnings options, squeeze with no catalyst, overconfident calls, ignored bearish signals.
Code Patch Generator
Generates precise Python code fixes for each pattern — under 20 lines, targeting the specific file and function. 5 pre-built patch templates, Gemini-generated patches for new patterns.
Proposal Review System
Saves proposals to proposed_updates/ for human review. You accept or reject. ATLAS tracks acceptance rate to improve future proposals.
Lessons Learned Report
HTML report (ATLAS_SELF_LEARNING.html): pattern table, pending proposals with code, acceptance history. Auto-generated after each analysis run.

How ATLAS Learns From Its Own Mistakes

The feedback loop that turns every loss into a permanent improvement.

1
Trade Made
ATLAS recommends a trade — deep research output with full rationale.
2
Outcome Graded
You run: python tracker.py grade — mark it WIN / LOSS / PARTIAL with exit price.
3
Pattern Detected
self_coder analyzes: was this IV crush on earnings options? Squeeze with no catalyst? High-confidence call that lost?
4
Code Fix Proposed
A precise Python patch (under 20 lines) is saved to proposed_updates/ — targets the exact file and function that caused the issue.
5
You Review and Accept
Run python auto_bot.py --proposals to see all pending proposals. Read the code, accept or reject.
6
Weights Auto-Tuned
auto_tuner shifts scoring weights toward signals that actually predicted the outcome. Atlas recalibrates confidence.
7
ATLAS Smarter
Next research call uses updated weights + tuned thresholds + fixed logic. The system is permanently better.
Why ATLAS proposes code but doesn't auto-apply it:

Financial code that autonomously modifies itself could have catastrophic, undetected bugs that cost you money. ATLAS generates precise, human-readable patches and saves them for you to apply after reading. The self-improvement loop is fully real — ATLAS gets genuinely smarter with every trade — but you stay in control of what actually goes into production. This is the same model used by top quant shops: machine-generated improvements, human final approval.
